核心结论 本项目的洞察

改造深度

仅 6 个官方包（opencode/core/schema/plugin/sdk/server）被装配层直接引用。opencode 的扩展点是 配置装配层（~/.config/opencode），而非源码 fork。

装配体系

61 个装配组件：43 skills + 7 agents + 6 mcp + 1 plugin + 1 tool + 1 command + 2 instructions + 1 config。真正触核心包的只有配置层，skills 大多挂外部服务。

skill 协作网络

33 条 skill 间作用关系：OpenSpec 12-skill 工作流闭环、superpowers 家族、DAG 三 skill 上下游链、amap 协作路由、recruit↔browser。装配层是一个有内部协作网络的体系。

历史脉络

18 个改造事件（2026-08-01~17）：输入缓存优化 → MCP 精兵策略 → 编码安全三层防御 → Reflection 自进化 → VLM 双通道修复 → 降本（Flash）→ 部分回滚 Pro。每次改造都需求驱动、有据可查。
