高德地图综合服务：POI 搜索、路径规划、旅游规划、周边搜索、热力图数据可视化。生成免费的高德网页链接（不消耗 API 配额），优先用于简单搜索/导航/周边查询，需要结构化数据时转交 amap-budget-control。

· AMAP_WEBSERVICE_KEY 环境变量 + 本地持久化配置
· package.json（Node 依赖）与 config.example.json

⑤ 为什么存在（why）

历史引入动机

0802 盘点标注开源+改造，上游为高德官方 MCP 改造，_meta.json 定义版本 2.0.1，含 Python（gaode_skill.py）+ Node（scripts/）+ JS（index.js）三类脚本。引入动机：生成免费的高德网页链接（POI 搜索/路径规划/旅游规划/周边搜索/热力图），不消耗 API 配额，解决简单地图查询也烧 API 配额的成本问题。7 大场景覆盖（关键词搜索/周边/热力图/路径规划/旅游规划等）。

当前需求驱动

amap MCP 已禁用后随 _SKILL.md 命名存档/休眠。保留价值：地图场景的零成本入口——简单搜索/导航/周边查询优先用本 skill 生成免费链接，需要结构化数据（批量 POI/路径步骤 JSON）时才转交 amap-budget-control（计次）。

⑥ 怎么用（how）

触发方式

触发关键词：搜、找、查、附近、周边、路线、规划、旅游、热力图、美食、酒店、景点、加油站、停车场（_SKILL.md description）；用户表达搜索地点/周边/路线/旅游/热力图意图时。当前因 _SKILL.md 命名不会自动加载（需显式引用）。

工作流/用法

1) 首次配置高德 Web Service Key（环境变量 AMAP_WEBSERVICE_KEY 或本地配置文件）；2) 场景判断（明确类别/位置周边/热力图/POI 详细/路径规划/旅游规划六场景）；3) 生成免费高德网页链接（不消耗配额）；4) 需要结构化数据时转交 amap-budget-control 用 MCP API。

协作关系

与 amap-budget-control（结构化数据转交）、amap-jsapi-skill（前端 JS 代码）、高德 Web Service Key + restapi.amap.com 埋点统计协作。
