⑥ 怎么用（how）

触发方式

触发关键词：多层窗口DAG、DAG接力、插件依赖分析、层次遍历、拓扑分层、PACKAGE-MAP覆盖度、多窗口交付；大型源码库 DAG 分析需要拆窗口接力时。

工作流/用法

· 窗口划分（核心集 base bundle → web-app → 其余），每窗口执行边界明确（完整执行+制定下一层计划）
· 每窗口内部：N 路并行 explore 采集（三硬依据+文件:行号）→ build-dag.py 层次遍历（BFS）拓扑分层+无环校验 → DATA 注入交互总览 → gen-html/gen-md/drawio 批量 → quality-gate 门控
· 窗口末尾落盘 PLAN-layerN.md 接力文件（数据接口+坑经验）→ 下一窗口继承 → PACKAGE-MAP 覆盖度终核（缺包=0 多包=0）+ 交付物逐项核对
