minimax-docx 装配层

skill-minimax-docx · skill · A6c-办公集成 · Layer 0

① 作用

基于 OpenXML SDK (.NET) 的专业 DOCX 文档创建、编辑与格式化技能，三管线：从零创建新文档、填充/编辑已有文档内容、套用模板格式化并带 XSD 验证门控。任何最终输出为 .docx 的任务（写报告/起草提案/做合同/填表/套模板）都强制使用本技能。

② 提供能力

· MiniMaxAIDocx.Cli 命令集（create/edit-content/apply-template/diff/validate/fix-order/merge-runs/analyze）
· XSD 校验器（wml-subset/aesthetic-rules/business-rules/common-types）
· CJK 排版库（Typography：CjkHelper/FontDefaults/PageSizes）
· 17 份 references 文档（OpenXML 百科全书×3/设计原则/场景指南/排障）
· python-docx 文本提取 + 预览/转换脚本（docx_preview/doc_to_docx）

⑤ 为什么存在（why）

⑥ 怎么用（how）

触发方式

SKILL.md 声明：任何产出/修改/格式化 Word 文档的任务 MUST 使用本 skill——包括用户说 write a report、draft a proposal、make a contract、fill in this form、reformat to match this template，即使没明说 docx，只要最终输出是 .docx 就触发。

工作流/用法

1) 三管线：A 从零创建 / B 填充编辑现有文档 / C 模板套用（XSD 校验门 gate-check）；2) Windows 下先 $env:PATH 前置 dotnet 路径，dotnet run --project $SKILL_DIR/scripts/dotnet/MiniMaxAIDocx.Cli -- <cmd>；3) 结构性操作（复杂表格/多节/页眉页脚/TOC/图片）直接写 C# task.csx（先读 Samples/*.cs 测试过的模式）；4) 输出后 XSD 校验 + 预览验证。

协作关系

与 minimax-xlsx（create-doc 文档创作组）、soe-resume（Word 管线依赖）、resume-builder、docx-template-translator（复杂期刊排版互补）、general 子Agent（翻译任务委派时附带本 skill）协作。
