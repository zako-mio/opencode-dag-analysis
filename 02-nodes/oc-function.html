function

oc-function · package · G13-边缘服务 · Layer 0

① 作用

Cloudflare Workers 上的会话分享同步服务。src/api.ts:15-114 定义 SyncServer Durable Object：WebSocket 订阅连接（fetch 握手 101 + ctx.acceptWebSocket，api.ts:20-37）、publish 将 session/info|message|part 变更写入 R2 Bucket 并广播给订阅者（api.ts:45-66）、share/assertSecret/clear 管理分享密钥与数据清理；Hono 路由提供 /share_create、/share_delete、/share_sync 等端点（api.ts:116-150）。

② 提供能力

· Durable Object 实时同步（WebSocket 广播 session 变更）
· R2 持久化分享数据（publish 写入 Bucket，api.ts:55）
· 分享密钥管理（share/assertSecret，api.ts:68-92）
· Hono HTTP API（share_create/share_delete/share_sync）
· GitHub App 认证（@octokit/auth-app 依赖）

③ 依赖（上游）

无内部依赖（或为叶子/外部）

④ 被依赖（下游）

无下游依赖

⑤ 为什么存在（why）

设计意图（官方）

作为云端分享的后端同步服务，利用 Cloudflare Durable Object 的 WebSocket 能力实现跨客户端实时会话同步，与 function 名（FaaS 云端函数）对应；R2 做持久化、secret 做访问控制。

改造关联

属官方底座，本机装配层未引用（本机无 Cloudflare 环境）。与 oc-enterprise、oc-web 组成官方云端分享三件套，本机离线部署不需要。

⑥ 怎么用（how）

怎么用

· Cloudflare Workers 部署（sst 管理，src/api.ts:1-7 import sst Resource + cloudflare:workers）；Hono 入口 src/api.ts:116-150 暴露 POST /share_create、/share_delete、/share_delete_admin、/share_sync 与 GET /share_poll（WebSocket 升级）、/share_data
· SyncServer Durable Object（api.ts:15-114）：fetch 握手 101 + acceptWebSocket 订阅（api.ts:20-37）、publish 校验 session 前缀后写 R2 Bucket 并广播（api.ts:45-66）、share/assertSecret/clear 管理密钥与清理（api.ts:68-109）
· 环境变量注入：Env 类型要求 SYNC_SERVER（DO namespace）、Bucket（R2）、WEB_DOMAIN（api.ts:9-13）

典型场景与协作

作为云端分享的后端同步服务：enterprise 的 /share 创建端点调用 function 的 share_create 生成密钥，分享页订阅 WebSocket 经 share_poll 实时接收 session 变更广播，数据落 R2 供 web 分享页拉取。与 web/enterprise 构成完整云端分享闭环。
