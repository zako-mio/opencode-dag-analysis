⑤ 为什么存在（why）

设计意图（官方）

为 opencode 核心提供零原生编译依赖的 Effect 化 SQLite 驱动（复用 node 内置 sqlite），与 @effect/sql-sqlite-node 定位一致但归属仓库自有实现，避免引入外部原生模块、保证跨平台可移植。

改造关联

属官方底座，本机装配层未引用（本机 opencode 数据走 server 侧 SQLite，未直接 import 此包）。官方依赖链：core 存储层经 drizzle 消费（见 effect-drizzle-sqlite 说明），本包是其底层驱动候选。

⑥ 怎么用（how）

怎么用

· exports "." → ./src/index.ts（package.json:11-13）；核心 API：make(config)（index.ts:49-52，Effect<SqliteClient>，含 filename/readonly/WAL/allowExtension 等配置 index.ts:32-43）与 layer(config)（index.ts:163-168，同时注册 SqliteClient + 泛型 Client.SqlClient 并注入 Reactivity.layer）
· TypeId 标记 "@opencode-ai/effect-sqlite-node/NodeSqliteClient"（index.ts:20-21）区分服务身份；loadExtension 支持扩展加载（index.ts:26）
· 基于 node:sqlite DatabaseSync（index.ts:59-70 WAL/外键），Semaphore(1) 串行化执行（index.ts:132-134），classifySqliteError 做 Effect 错误分类（index.ts:15）

典型场景与协作

作为核心存储层的 Effect SQLite 驱动底座：core 的数据库层经 layer() 注入 SqliteClient 服务后，上层只需 Effect.provide 即可获得类型安全 SQL 能力。与 effect-drizzle-sqlite 配合：后者把 Drizzle 查询桥接到任意 Effect SqlClient（含本包实现）。
