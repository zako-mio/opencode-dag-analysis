⑤ 为什么存在（why）

历史引入动机

完全自创 skill（0802 盘点标注完全自创，无上游）。引入动机：高德 Web 服务 API 有 5000 次/天免费额度，Agent 若不加控制地调用 MCP amap 工具会超限产生费用。0802 盘点（附录 C 时间线）确认 amap 三件套为早期引入（Provider 迁移同期）。本 skill 负责三级预算预警 + 用量追踪（amap-usage.json 计数文件），解决 API 成本失控问题。0802 盘点发现 amap 系列用 _SKILL.md 命名刻意禁用（amap MCP disabled），MCP 精兵策略裁撤。

当前需求驱动

amap MCP 已禁用（enabled=false，精兵策略：12 工具约 2000 tokens 极低频），本 skill 随 _SKILL.md 命名保持存档/休眠状态，仅当用户显式提及地图/导航/位置/POI/天气/路径规划等关键词时激活（description 声明）。保留价值：若按需重新启用 amap MCP，预算控制规则（精准触发/用量追踪/超限预警/替代方案）即生效。

⑥ 怎么用（how）

触发方式

触发关键词：导航、路线、路径规划、驾车、公交、地铁、步行、骑行、地图、高德、POI、周边搜索、附近、餐厅、酒店、加油站、停车场、评分榜单、天气、测距、距离、地址转坐标、经纬度、IP定位、我在哪、amap。一级触发词必须激活；二级结合上下文判断；纯聊天地名提及/比喻/产品定位明确不激活。

工作流/用法

1) 精准触发匹配（一级/二级触发词规则）；2) 每次调用前检查 amap-usage.json 用量计数；3) 接近 5000 次/天免费限额时预警；4) 额度不足给出清晰报错与替代方案（优先引导 amap-lbs-skill 免费链接）；5) 三 skill 协作策略：简单搜索用 amap-lbs-skill（免费）；结构化数据用本 skill（计次 MCP API）；前端 JS 代码用 amap-jsapi-skill（免费）。

协作关系

与 amap-lbs-skill（免费链接，优先路由）、amap-jsapi-skill（前端 JS 开发）、amap MCP（13 个 amap_* 工具授权）、amap-usage.json 计数文件协作。
