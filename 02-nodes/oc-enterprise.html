enterprise

oc-enterprise · package · G10-应用 · Layer 0

① 作用

基于 SolidStart 的企业版/云端分享服务。src/app.tsx:1-14 用 @opencode-ai/ui 的 Provider（Marked/Dialog/I18n）搭建 SSR 应用根并做 locale 检测；src/routes/api/[...path].ts:1-30 用 Hono + hono-openapi 定义 OpenAPI 文档与 /share 创建端点（zod schema，经 core/share.ts 与 sst Resource 持久化）；routes/share/[shareID].tsx 用 @opencode-ai/session-ui 的 SessionTurn/SessionReview/MessageNav 渲染只读分享会话；core/storage.ts 提供基于 R2 的存储。

② 提供能力

· Hono OpenAPI /api 端点（/share 创建、文档，routes/api/[...path].ts:20-27）
· 只读分享会话页面（routes/share/[shareID].tsx，复用 session-ui 组件）
· R2 对象存储封装（core/storage.ts）
· SSR 应用根与多语言检测（app.tsx:58 detectLocale）
· cloudflare 部署目标支持（build:cloudflare script）
