⑥ 怎么用（how）

触发方式

1) 读取 pending.json 中 status=processing 的 cycle（含 4 层输入：Layer A GATE 自评+COMPLEXITY+决策 / Layer B 子Agent JSON+聚合 / Layer C MEMORY 快照 / Layer D 留档报告）；2) 生成 memory_entries / skill_proposals；3) 写回 pending.json (status=done, results 填充)；4) 触发机制：Build 末尾写 pending → 下一轮对话 MEMORY.md 自引用检查 waiting_count>0 → 标 processing 委派（Path A 异步）。

工作流/用法

每个 Plan+Build 周期后（Build 末尾封装 4 层输入）；下一轮用户消息启动时异步处理；/reflection 审阅其产出。

协作关系

plan/build（4 层输入来源）、agent-reflection skill（方法论）、command-reflection（/reflection 交互确认写入）、pending.json 状态机。
