session-ui

oc-session-ui · package · G9-UI组件 · Layer 3

① 作用

会话级 UI 组件集，介于基础组件库与完整应用之间。src/components/ 提供 SessionTurn、SessionReview、MessagePart、message-file、session-diff、line-comment 等会话渲染组件，并含 markdown 流式渲染整套管线（markdown-stream.ts + markdown-worker.ts + markdown-cache.tsx，用 Worker 实现增量渲染）；src/pierre/ 提供 file-find/file-selection/diff-selection/media 等代码交互原语；src/context/data.tsx 提供会话数据 Provider（被 enterprise share 页复用）。

② 提供能力

· SessionTurn/SessionReview 会话轮次与评审组件
· MessagePart/message-file/session-diff 消息部件与差异展示
· Markdown 流式渲染管线（worker + stream + cache，markdown-stream.ts:12）
· 文件查找/选择/差异选择交互原语（pierre/ 目录）
· 会话数据 context（context/data.tsx）
· PromptInput v2 输入框（v2/components/prompt-input/）

⑤ 为什么存在（why）

设计意图（官方）

把会话级渲染（消息/轮次/评审/markdown 流）从 app 中剥离，使 app 与 enterprise 共享同一套会话表达，避免重复实现；pierre/ 目录进一步抽象代码交互原语供应用层装配。

改造关联

属官方底座，本机装配层未引用。官方依赖链中同时被 oc-app 与 oc-enterprise 依赖（package.json 均列 @opencode-ai/session-ui workspace:*），是分享场景的公共渲染源。

⑥ 怎么用（how）

怎么用

· 会话级组件子路径导入：package.json:7-25 exports 提供 ./session-diff、./message-file、./message-part-text、./markdown-stream、./markdown-cache、./line-comment-styles、./pierre/*、./context/* 等，app 与 enterprise 直接复用（app/src/app.tsx:6 import File from @opencode-ai/session-ui/file）
· markdown 流式渲染管线：markdown-stream.ts + markdown-worker.ts + markdown-cache.tsx 组合（Worker 增量渲染），app 的会话页经 context/data.tsx Provider 消费
· PromptInput v2：./v2/prompt-input（index/interaction/store/types）新一代输入框子路径导出

典型场景与协作

作为 app（桌面/Web 会话页）与 enterprise（只读分享页 routes/share/[shareID].tsx 复用 SessionTurn/SessionReview/MessageNav）共同依赖的会话表达层：app 渲染完整可交互会话，enterprise 用同一套组件渲染只读分享，避免两处重复实现会话 UI。
