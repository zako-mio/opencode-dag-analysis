console-core

oc-console-core · package · G16-Console · Layer 1

① 作用

Console 后端领域层：基于 drizzle-orm + PlanetScale 的数据库访问、Actor 权限上下文、以及 Account/User/Workspace/Key/Billing/Subscription/Model/Provider 等 CRUD 与计费逻辑。src/drizzle/index.ts 封装事务与上下文，src/account.ts 处理账号创建/删除（含级联清理 key、coupon、auth），src/workspace.ts 创建 workspace 并默认生成管理员与 API key，src/billing.ts 对接 Stripe 做 credits 充值。

② 提供能力

· Database 封装：PlanetScale drizzle 客户端 + 事务/上下文（src/drizzle/index.ts:36）
· Actor 权限上下文：请求用户/角色/workspace 断言（src/actor.ts）
· 账号生命周期：create/remove/fromID，删除级联清理（src/account.ts:13,27）
· workspace 创建与成员管理（src/workspace.ts:17）
· API Key 管理与角色隔离（src/key.ts:11）
· Stripe 计费：credits 充值/订阅/用量计费（src/billing.ts:22,29）
· 模型/Provider 目录与 ZenData 模型成本定义（src/model.ts）
· 订阅限额：free/lite/black 阶梯（src/subscription.ts:7）
· 全量 drizzle schema SQL（src/schema/*.sql.ts，account/auth/billing/key/model/provider/referral/user/workspace/ip/benchmark）
· 邀请邮件渲染（动态 import console-mail，src/user.ts:142）

⑤ 为什么存在（why）

设计意图（官方）

用 namespace + fn(zod, impl) 模式把参数校验(zod) + Actor 权限上下文 + DB 事务统一封装，业务函数即 API 边界——console-function/app 直接 import 复用，避免三处重复实现；Actor（account/public/user/system 四型）贯穿所有查询做租户隔离（workspaceID 过滤），是控制台多租户安全的核心机制。

改造关联

本机未改该包；装配层对它的借用体现在方法论：本地自定义工具 read.ts 的 zod args schema、子Agent 的 JSON 返回合约、以及 mission-archiving 的 5 段报告，都沿用了 zod 定义契约 + 结构化输出这一 console-core 模式。

⑥ 怎么用（how）

怎么用

被 console-app / console-function / console-support 以 workspace:* 依赖引用（exports 映射 ./src/*.ts 直读 TS 源码）。业务入口均为 fn(zodSchema, impl) 封装的函数：Actor.provide 提供 account/user/system 上下文（AsyncLocalStorage），Database.use/transaction 执行 drizzle 查询（PlanetScale/MySQL + postgres 双驱动），Key/Workspace/User/Provider/Subscription/Billing/BlackData/LiteData/Referral 等 namespace 各司其职。DB 操作经 bun sst shell drizzle-kit（script/db）迁移。

典型场景与协作

console 全栈业务逻辑层：workspace 创建（含默认 API Key 与 billing 记录）、Key 生成（sk- + 64 随机字符）、model/provider 目录（ZenData 的 Format: anthropic|google|openai|oa-compat 与 cost/cacheRead/byok/sticky/trial 字段）、订阅限额（free/lite/black 三档 rolling/weekly/monthly 窗口）、Stripe 计费（billing.ts 的 Stripe client + 4.4% 处理费公式）、AWS SES 邮件（aws.ts）。
