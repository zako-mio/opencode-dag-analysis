⑤ 为什么存在（why）

历史引入动机

2026-08-04 Superpower 安装引入（同 superpowers-feature-workflow），obra/superpowers 仓库 3 Bundles 之一。引入动机：会话后知识沉淀的规范化——把近期工作教训按四类分类（持久事实/当前状态/会话结果/可复用教训）回写项目记忆，防噪音、防一次性修复升格为规则。安装时评估认为 .superpowers-memory/ 模板与本地 MEMORY.md 体系重叠故不装脚手架，仅保留 workflow skill 本身。

当前需求驱动

⑥ 怎么用（how）

触发方式

显式 opt-in：用户想保留近期工作教训、点名 $superpowers-learning-workflow 或仓库策略要求时触发；不默认启用（SKILL.md）。

工作流/用法

1) 回顾近期工作/决策/验证证据；2) 分类为持久事实、当前状态、会话结果、可复用教训四类；3) .superpowers-memory/ 存在则更新 PROJECT_CONTEXT.md、CURRENT_STATE.md、journal、LEARNING_BACKLOG.md；4) 不存在则告知用户装脚手架或存普通项目文档；5) 稳定事实与临时笔记分离；6) 总结下一会话该记住什么。Guardrails：不写任务噪音进 PROJECT_CONTEXT、一次性修复不升格规则、不自动编辑 skill 库。

协作关系

与 superpowers-feature-workflow（交付流程配套）、Reflection 系统（0805 引入的本地替代/互补机制：pending.json + reflection-worker）、MEMORY.md 记忆体系协作。
