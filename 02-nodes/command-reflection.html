① 作用

/reflection 原生命令（frontmatter：description + agent=build），命令体自包含执行不依赖其他文档。流程：读 pending.json（校验 JSON 合法）→ 按 $ARGUMENTS 子动作过滤（无参/all 展示全部 done；memory/skill 按条目类型过滤；status 仅输出 meta 计数；browse 仅列 id/cycle_type/created_at）→ 用 question 工具逐条 yes/no/edit 确认 → yes 写入 MEMORY.md（§ 分段）或 Reflection\skills\{category}\{name}\SKILL.md（含 frontmatter）→ 清理队列并原子写回（先备份 pending.json.bak-YYYYMMDD，同步更新 meta 计数）。门控：逐条审阅不批量跳过；MEMORY.md 超 3500 字符提示手动整理；UTF-8 写后校验中文完整。
