⑥ 怎么用（how）

怎么接入

chrome-debug.ps1：powershell -ExecutionPolicy Bypass -File $env:USERPROFILE\.config\opencode\scripts\chrome-debug.ps1（检查 http://localhost:9222/json/version，无则启动 Chrome + --remote-debugging-port=9222 + --user-data-dir 独立 profile）；browser-harness 通过 BU_CDP_URL 连接 daemon；browser-harness --doctor 诊断；远程/云浏览器用 browser-harness auth login（Browser Use cloud）。

装配层调用

管道喂 Python 脚本：$pyScript | browser-harness.exe（Windows 用 @"..."@ heredoc，不用 <<PY）；流程：new_tab(url) 首次导航 → wait_for_load() → capture_screenshot() 看状态 → js()/click_at_xy() 交互 → 完成后 close-chrome-tabs.ps1 -KeepFirst 收尾；原始能力用 cdp("Domain.method", ...)。
