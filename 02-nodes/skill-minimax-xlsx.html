minimax-xlsx 装配层

skill-minimax-xlsx · skill · A6c-办公集成 · Layer 0

① 作用

打开/创建/读取/分析/编辑/验证 Excel 电子表格（.xlsx/.xlsm/.csv/.tsv）。覆盖从零创建 xlsx、无格式损失编辑已有文件、公式重算与校验、专业财务格式化标准。内置 Windows 非 ASCII 编码双层防御（UTF-8 文件路由）与强制写后读回验证。

② 提供能力

· Python 脚本集（json2xlsx/xlsx_reader/xlsx_pack/unpack/formula_check/style_audit/add_column/insert_row/shift_rows/libreoffice_recalc/shared_strings_builder）
· minimal_xlsx 模板（workbook/styles/sharedStrings）
· OOXML 速查表 + 创建/编辑/修复/格式化/验证/读取分场景 references
· Readback 验证规则（列数/行数/抽样单元格三重确认）
· 编码安全两层防御规范

③ 依赖（上游）

无内部依赖（或为叶子/外部）

④ 被依赖（下游）

无下游依赖

⑤ 为什么存在（why）

历史引入动机

来自 MiniMax（skill marketplace 分发），本地重度改造：Python 管线（11 脚本）+ templates/ + references/（7 文件）。引入动机：Agent 需要程序化处理 Excel/电子表格（创建/编辑/分析/验证），且曾遭遇 Windows PowerShell 5.1 编码事故——$OutputEncoding 默认 ASCII，管道传中文导致 Python dict 静默去重（真实事故：11 列变 3 列），因此内置 UTF-8 编码双层防御（非 ASCII 入文件不走管道）+ 回读验证规则（写后必回读校验列数/行数/采样值）。

当前需求驱动

简历投递跟踪表读写（recruit-assist 的 tracker_writer.py 调用其 XML 解包-编辑-打包流程，严禁 COM）、网申数据导出、财务分析（0807 利润表任务）、create-doc preset Excel 能力。0815 补 LibreOffice 26.2.5.2 解锁动态重算 + .xls 转换（P6 实测 SUM/IF/乘法重算 + xlsx-xls-xlsx 双程无损）。

⑥ 怎么用（how）

触发方式

触发词：spreadsheet、Excel、.xlsx、.csv、pivot table、financial model、formula、或任何要求以 Excel 格式产出表格数据的请求（SKILL.md description）。

工作流/用法

1) 首选 json2xlsx.py：JSON 数组 + map.json 生成带样式/验证的工作簿（中文全在 UTF-8 JSON 文件，退出码 0=写并验证通过）；2) 编辑现有文件：解包后 xlsx_insert_row.py / xlsx_add_column.py 结构性修改再打包（自动更新 sharedStrings/样式/SUM 公式，零格式损失）；3) 行定位规则：grep sheet XML 找标签文本，绝不依赖预览行号；4) 每次写入后回读验证（列数/行数/采样单元格）。

协作关系

与 recruit-assist（tracker_writer.py 依赖）、minimax-docx（create-doc 组）、create-doc preset、LibreOffice（动态重算外部工具）协作。
