⑤ 为什么存在（why）

历史引入动机

0801 P0 新增：drawio-worker 配置 Flash 模型；0803 Drawio工具链优化关键转折：曾给 drawio-worker 新增 agent.prompt 字段（强制导出+防越界+VLM 校验规则），但源码级逆向确认 agent.prompt 位于系统提示词位置 0，新增后缓存前缀从 2 变 3，drawio-worker 无法复用其他子Agent 缓存——用户判定'这个代价不值得'→ 回退 prompt 字段；per-agent 行为约束改为经 drawio-reference skill + 主Agent 的 Skills to Load 传递；MCP 路由规则从'必要时加载'改为'必须包含 drawio-reference'（禁止弱化表述）。

当前需求驱动

固定 Flash（图表生成无需 Pro 推理）；permission 仅放行 drawio_*（L3 最小权限）；刻意不设 agent.prompt 字段避免缓存前缀碎片化；委派刚性约束：prompt 必须精确写入'drawio-reference: 图表规范与导出验证'，违者导致不可靠 CLI 导出产生截断 PNG。
