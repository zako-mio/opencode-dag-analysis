⑥ 怎么用（how）

触发方式

仅 OpenSpec 维护者使用（SKILL.md description）；用户请求 release / prepare a release / continue / resume 时触发；请求 status/readiness/advice 时默认只读审计。

工作流/用法

1) 发布审计：gh repo view 验证仓库、要求 gh/git/pnpm 认证、git fetch origin main；2) 找最新稳定 release（gh release list --exclude-drafts --exclude-pre-releases）；3) 区分两类 PR（Changeset PR 人工添加 .changeset/*.md；Version Packages PR 自动化 changeset-release/main）；4) 脏 checkout 时用临时 worktree 做发布提交；5) 永不批准自己的 PR（人工审查是刻意门）；6) merge-queue 进队不等于合并，等 GitHub 报 mergedAt 且 main 上有该 commit；7) 暂停时报告 URL/状态/所需人工动作。

协作关系

与 gh/git/pnpm CLI、GitHub（Fission-AI/OpenSpec）、Changesets action（Version Packages PR）、openspec 系列 skill（openspec-plan preset 内降权成员）协作。
