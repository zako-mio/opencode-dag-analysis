auto-mode 装配层

instr-auto-mode · instruction · A4-命令指令 · Layer 5

① 作用

全局共享前缀协议（Cache-Stable，所有 Agent 加载，session 内字节稳定以维持 DeepSeek prefix-cache）。核心内容：①强制 GATE 门控（范围/深度/操作/风险 4 维 1-5 分自评→总分→Daily≤12/Deep≥13，主Agent 强制输出）；②Variant 运行时控制（Ctrl+T 切换、DeepSeek 思考模式有效参数表、被忽略参数说明）；③Universal SubAgent Rules（结构化 JSON 返回、身份约束、工具/错误处理/通信规范）；④通用编码纪律（验证证据、从磁盘读取、路径本地化、元数据不入输出）；⑤缓存感知原则（静态前缀/动态末尾）；⑥并行批处理规范；⑦输出规模控制；⑧故障自愈协议（3 次重试上限）；⑨Session Memory 阶梯式压缩模板（L1 剪枝→L2 结构化→L3 摘要）。

② 提供能力

全 Agent 统一行为协议（门控/委派/编码/缓存/容错/压缩）、成本控制基准（Daily 8192/Deep 16384 tokens）
