当前需求驱动

amap MCP 已禁用后随 _SKILL.md 命名存档/休眠（0815 桥接 opencode-skill-index 标注 amap-jsapi-skill 存档）。保留价值：若重新启用地图开发场景（编写/调试地图前端 JS 代码），本 skill 提供 JSAPI v2.0 (WebGL) 完整参考，且不消耗 API 配额（免费）。

⑥ 怎么用（how）

触发方式

触发关键词：地图开发、JSAPI、WebGL地图、地图初始化、覆盖物、点标记、Marker、Polyline、Polygon、InfoWindow、热力图、图层、地理编码、路径规划开发、AMap、amap-jsapi（_SKILL.md description）。当前因 _SKILL.md 命名不被 opencode glob 匹配而不会自动加载（需显式引用）。

工作流/用法

1) script 标签加载 loader.js（webapi.amap.com/loader.js）；2) 强制安全密钥配置（window._AMapSecurityConfig.securityJsCode，从环境变量取，禁硬编码，生产用 serviceHost 代理）；3) AMapLoader.load({key, version 2.0, plugins}) 初始化地图（3D 视图/缩放/中心点）；4) 按场景查 references/（map-init/view-control/marker/vector-graphics/info-window/context-menu/events/layers 等）写覆盖物与交互代码。

协作关系

与 amap-lbs-skill（免费链接）、amap-budget-control（结构化数据计次）三 skill 协作（_SKILL.md 协作说明：本 skill 只负责前端 JS 代码）。
