⑥ 怎么用（how）

触发方式

触发关键词：源码解析、架构解析、source analysis、9层解析、DAG依赖链、跨层联动、源码clone、架构文档；解析大型开源项目源码架构时。

工作流/用法

· 快照准备（浅 clone+官方文档镜像双依据）→ 层级骨架先行（9 层抽象+目录交叉索引）→ 三源交叉验证（印证/矛盾/独家/待裁决/参考五类管理）
· 按层分派 explore 子Agent 并行解析，每条结论要求三硬依据+源码行引用，返回结构化 JSON
· 归一化与裁决（口径不一致由主Agent 终裁，异构结构统一 schema ≤2 次重试）→ 跨层联动矩阵 → 图表/文档生成 → 质量门控 → checkpoint 续传

协作关系

委派 explore 子Agent 按层并行；产出供 multi-window-dag-delivery（DAG 分析）与 cytoscape-dag-visualization（渲染）消费；与 drawio-worker（图表）协作
