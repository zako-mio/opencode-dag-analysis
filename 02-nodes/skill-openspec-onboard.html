触发方式

首次使用 OpenSpec 的用户请求引导（description 触发词"引导""教程""首次"）；或显式 /openspec-onboard。

工作流/用法

· 预检 OpenSpec CLI 是否安装（未装则提示先安装）
· 欢迎 + 选任务（TODO/FIXME 扫描 + git 活动）
· 在真实代码库边做边讲完整周期（建变更→四工件→实现→归档），15-20 分钟实战走查

协作关系
