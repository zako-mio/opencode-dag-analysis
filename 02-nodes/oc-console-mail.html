console-mail

oc-console-mail · package · G16-Console · Layer 2

① 作用

邮件模板包：无 src/，全部为 emails/ 下的 jsx-email 模板与共享组件/样式。emails/templates/InviteEmail.tsx 是唯一业务模板（workspace 邀请邮件），被 console-core 的 User 邀请逻辑动态 import 渲染（console/core/src/user.ts:142）。包 exports 映射到 ./emails/templates/*，纯前端渲染无服务逻辑。

② 提供能力

· InviteEmail 邀请邮件模板（React/jsx-email，emails/templates/InviteEmail.tsx:26）
· 共享邮件组件与内联样式（emails/components.tsx、emails/styles.ts）
· 静态邮件资源：字体 woff2/logo/箭头图（emails/templates/static/）
· 本地预览命令（email preview emails/templates）
