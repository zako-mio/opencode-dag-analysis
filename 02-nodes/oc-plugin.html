plugin

oc-plugin · package · G7-插件SDK · Layer 4

① 作用

插件 SDK。src/index.ts:20-80 定义 Plugin/PluginInput/Config/Hooks 等公共类型，基于 @opencode-ai/sdk 客户端访问服务；src/tool.ts:3-20 定义 ToolContext/ToolResult。提供 v2 双运行时：effect 版（src/v2/effect/：plugin/context/agent/command/skill/catalog/integration/filesystem/event 等 14 模块）与 promise 版（src/v2/promise/），并含 TUI 插件类型（src/tui.ts:1-40 基于 @opentui）。

· Effect 原生 v2 插件 API：agent/command/skill/catalog/integration 注册（packages/plugin/src/v2/effect/plugin.ts）
· Promise 风格 v2 插件 API（packages/plugin/src/v2/promise/index.ts）
· TUI 插件接口（基于 @opentui，packages/plugin/src/tui.ts:19-33）
· shell 工具封装（packages/plugin/src/shell.ts）
