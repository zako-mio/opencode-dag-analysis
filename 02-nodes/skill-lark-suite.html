⑤ 为什么存在（why）

改造盘点（2026-08-02）标注为开源+改造，上游 yjwong/lark-cli（53 星，Go，MIT），lark-cli v1.0.76 已本地安装。SKILL.md 为路由包装层（意图路由映射表指向 23 个域文件），引入动机是让 Agent 能通过 CLI 操作飞书全部业务域（日历/消息/文档/云盘/多维表格等），解决简历求职流程中飞书表格同步（网申进度表）与日常办公文档操作需求。0802 盘点发现 23 个域文件中 20 个为占位，修复为 Fallback 策略首位加 lark-cli skills read 动态加载（v1.0.76 自带 27 个官方内置 skill）。
