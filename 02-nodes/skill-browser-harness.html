⑥ 怎么用（how）

触发方式

SKILL.md description：Always use browser-use for any web interaction: automation, scraping, testing, or site/app work——任何网页交互/自动化/爬取/测试/站点应用工作。skill/browser-harness 目录为 skills.paths 单独注册路径（0802 起双路径之一）。

工作流/用法

1) 前置：chrome-debug.ps1 启动 Chrome 远程调试（检查 9222 端口，无则独立 profile 启动）；2) PowerShell @"..."@ heredoc 写 Python 代码后管道发给 browser-harness.exe（helpers 预导入，首次导航 new_tab(url)）；3) js() 需 return/print，复杂操作分块抓取；4) 连接失败用 --doctor 诊断，daemon 挂了重跑 chrome-debug 脚本，runtime 目录残留则删除重建。

协作关系

与 recruit-assist（投递核心依赖）、frontend-design（create-web preset 渲染实测）、create-web preset、Chrome（ext-chrome 外部）、browser-harness daemon（BU_CDP_URL localhost:9222）、VLM 图片校验协作。
