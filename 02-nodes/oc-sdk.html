⑤ 为什么存在（why）

设计意图（官方）

对外发布（npm 包）的官方 SDK，将 opencode 内部 server 的 openapi.json 编译为类型安全的客户端，同时提供进程级 server 托管，供第三方应用与 plugin 使用。

改造关联

本机未直接引用 sdk（vision 插件经 @opencode-ai/plugin 消费类型，agent 经 CLI/HTTP 而非 SDK 连接），属官方底座；本机的改造接口是配置层（opencode.jsonc）与插件层（plugin-vision-interceptor），不触及 SDK 客户端面。

⑥ 怎么用（how）

怎么用

· 入口：sdk/js/src/index.ts；核心 client 工厂 createOpencodeClient(config)（src/client.ts:55-76，把 directory 注入 x-opencode-directory 头并 wrap 错误）；类型面 re-export 自 src/gen/（openapi.json 编译产物）。
· 导出（package.json exports）：./client、./server、./v2、./v2/client、./v2/gen/client、./v2/server、./v2/types；server.ts:17-40 createOpencodeServer(options) 用 cross-spawn 拉起 opencode serve 子进程（hostname/port/signal 托管），process.ts 提供 stop/bindAbort（win32 下 taskkill 树杀）。
· v2：src/v2/client.ts、src/v2/server.ts、src/v2/data.ts、src/v2/index.ts 提供 Effect 原生类型面（plugin/tui/enterprise/slack 均消费 @opencode-ai/sdk/v2）。

典型场景与协作

sdk 是官方对外发布（npm）的客户端：第三方应用用 createOpencodeClient 连远程 server、用 createOpencodeServer 进程内托管本地服务；plugin 包 import 它做 SDK 类型（plugin/src/index.ts:1-12），tui/enterprise/slack 均依赖（official-dag 中 8 个反向引用）。报告-03 对请求链路/缓存的分析中 SDK 出现 40 次，是协议端到端消费的关键路径。
