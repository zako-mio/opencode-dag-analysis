web

oc-web · package · G11-文档站点 · Layer 0

① 作用

基于 Astro + Starlight 的文档与分享站点。src/pages/s/[id].astro:2-8 渲染会话分享页（Share.tsx 消费 opencode/session 类型，通过 API URL 拉取分享数据）；src/pages/[...slug].md.ts:19-34 提供 docs 内容 API（按 slug 返回 markdown 文档）；src/content/docs/ 含多语言（en/zh/ar/bs/de/...）文档与代码示例（大量引用 @opencode-ai/plugin 与 @opencode-ai/sdk 的用法）。devDependencies 引用 opencode 包（opencode: workspace:*）。

② 提供能力

· 会话分享查看页（s/[id].astro + components/Share.tsx）
· docs 文档 API 端点（pages/[...slug].md.ts:19）
· Starlight 多语言文档站（content.config.ts + i18n/）
· 分享 WebSocket 连接状态 UI（Share.tsx:15 status 机）
