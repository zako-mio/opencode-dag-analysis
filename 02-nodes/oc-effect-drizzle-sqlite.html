⑤ 为什么存在（why）

设计意图（官方）

让 Drizzle 类型安全的 schema 查询能在 Effect 生态（SqlClient/Stream/Layer）中运行，供核心存储层使用且依赖可注入、可测试，是 core 数据库层的类型安全 + 效果系统双重要求的产物。

改造关联

属官方底座，本机装配层未引用。官方依赖链：core 的 database/sqlite.ts 使用 drizzle ORM（drizzle-orm 依赖），本包提供其 Effect 化接入面；effect-sqlite-node 是其底层驱动实现。

⑥ 怎么用（how）

怎么用

· exports："."（index.ts 汇总）、./effect-sqlite（driver）、./effect-sqlite/migrator、./sqlite-core/effect（package.json:12-17）；index.ts:1-7 导出 EffectLogger、driver/session 全量与 migrate
· 工厂：make()（driver.ts:49-52，Effect.fn 返回 EffectSQLiteDatabase）、makeWithDefaults（driver.ts:75）；会话：EffectSQLiteSession（session.ts:35，prepareQuery + Effect 化事务）、EffectSQLiteTransaction（session.ts:206）
· migrate（sqlite-core/effect/session.ts:426）执行迁移；查询构建器 sqlite-core/effect/ 提供 select/insert/update/delete/raw/count 全套 Effect 化 API

典型场景与协作

作为 Drizzle ORM 与 Effect 生态的桥接层：core 存储层定义 drizzle schema 后，经 make() 桥接到任意 Effect SqlClient（driver.ts:30-46 注释明示可配 @effect/sql-sqlite-node/bun 或本仓库 effect-sqlite-node），使查询以 Effect Effect/Stream/Layer 形式参与依赖注入与测试。
