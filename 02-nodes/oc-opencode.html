opencode

oc-opencode · package · G19-主入口 · Layer 0

① 作用

主应用/CLI 入口。src/index.ts:45 用 yargs 装配 run/serve/tui/agent/acp 等全部子命令；src/cli/tui/layer.ts:1 经 @opencode-ai/tui 拉起终端 UI；src/server/server.ts:4-13 组装 Node HTTP/WebSocket 服务器与 HttpApi 路由。会话编排由 src/session/processor.ts:26-27 驱动（回退 LLM、工具调度），工具清单在 src/tool/registry.ts:4-16 注册（read/edit/shell/glob/grep/webfetch 等 20+ 内置工具）。

② 提供能力

· CLI 入口：yargs 子命令体系（run/serve/tui/agent/acp/github 等 20+ 命令，packages/opencode/src/index.ts:45）
· HTTP/SSE/WebSocket 服务器实例（packages/opencode/src/server/server.ts:27-30）
· 会话处理器：消息输入→LLM 请求→工具执行的编排循环（packages/opencode/src/session/processor.ts:32）
· 内置工具集：read/write/edit/shell/glob/grep/task/webfetch 等（packages/opencode/src/tool/registry.ts:4）
· Session 状态机、compaction/retry/summary/reminders 生命周期（packages/opencode/src/session/*）
· 插件宿主：加载外部 plugin 与 provider 扩展（packages/opencode/src/plugin/index.ts:8）
· Code Mode 工具桥接（packages/opencode/src/tool/code-mode.ts:4）
