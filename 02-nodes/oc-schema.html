schema

oc-schema · package · G1-数据模型 · Layer 5

① 作用

纯类型/数据模型包，仅依赖 effect（package.json:14-16）。以 Effect Schema 定义全部领域类型：Session/SessionInput/SessionMessage（src/session*.ts）、Event 与 Durable 事件清单（src/event.ts、event-manifest.ts、durable-event-manifest.ts）、Provider/Model（src/provider.ts、model.ts）、Permission、Prompt、Agent 等 40+ 模型。src/index.ts:1-28 统一 re-export；src/schema.ts:3-10 提供 AbsolutePath/RelativePath/DateTimeUtc 等基础 branded schema。

② 提供能力

· 领域数据模型：Session/Message/Event/Permission/Provider/Model 等（packages/schema/src/index.ts:1-28）
· Effect Schema 编解码与校验基础（packages/schema/src/schema.ts:3-30）
· 事件定义清单：Event/EventManifest/Durable（packages/schema/src/event.ts、durable-event-manifest.ts）
· V1 兼容模型（packages/schema/src/v1/session.ts、question.ts、permission.ts）
