server

oc-server · package · G4-服务端 · Layer 1

① 作用

HTTP/SSE 服务器实现层。src/api.ts:5-8 用 @opencode-ai/protocol/api 的 makeDefaultApi 装配 HttpApi，并注入 LocationMiddleware/SessionLocationMiddleware 具体中间件；src/routes.ts:1-13 把 core 的各类服务（SessionV2/SessionExecution/LocationServiceMap/Database/ToolOutputStore 等）装配为 Effect Layer；src/handlers.ts:1-40 合并 19 个 handler（session/message/agent/model/provider/fs/event/pty 等），每个 handler 将 HTTP 请求桥接到 core 领域服务。

② 提供能力

· HttpApi 装配与中间件注入（packages/server/src/api.ts:5-8）
· 19 个资源 handler（packages/server/src/handlers.ts:21-40）
· core 服务到 HTTP 层的 Effect Layer 桥接（packages/server/src/routes.ts:1-13）
· 授权/会话定位中间件（packages/server/src/middleware/authorization.ts、session-location.ts）
· CORS 与 auth 基础（packages/server/src/cors.ts、auth.ts）
