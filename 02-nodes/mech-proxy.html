⑤ 为什么存在（why）

历史引入动机

WSL2 代理网关 172.29.0.1:7890。0813 时子Agent 联网给代理；0822 策略改为默认直连。动机：区分国内直连与境外被墙访问。

当前需求驱动

模型 API 链不读代理 env 必须直连；境外被墙站点需显式 curl -x；国内源全直连。

⑥ 怎么用（how）

触发方式

按访问目标分域：模型 API/国内源直连；境外被墙站点用 -x 代理；git 固定定向代理。

工作流/用法

默认直连（proxy_off 无全局 env）；境外需求手动 curl -x 或依赖 git 定向代理；proxy_on 后 no_proxy 保国内直连。

协作关系

config-main；instr-auto-mode；agent-general/agent-explore；git 全局代理。
