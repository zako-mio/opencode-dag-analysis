⑥ 怎么用（how）

触发方式

触发关键词：失败复盘、为什么失败、复盘、postmortem、教训、项目失败分析；用户对失败项目要求系统性复盘时。

工作流/用法

· Step1 根因层级判定：对照参考项目判断架构模式是否一致（路线错误最高优先级）
· Step2 并行探索：委派 explore-failed-project（dead code 审计）与 explore-reference（核心模式统计+gap 分析）两个 explore Agent
· Step3 资产盘点 A/B/C 三级（复用价值×影响力排序）+ 产出 v2 设计建议与 MVP 最小化清单 + 5 段式复盘报告

协作关系

委派 2 个 explore 子Agent（失败项目/参考项目）；产出资产清单交给 reusable-asset-inventory；复盘结论回流 Reflection 系统（本 skill 自身即反思产物）
