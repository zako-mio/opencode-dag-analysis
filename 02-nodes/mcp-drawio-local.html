drawio-local 装配层

mcp-drawio-local · mcp · A2-MCP · Layer 0

① 作用

本地 MCP，与主 drawio 同一实例（同 index.js），但注入环境变量 DRAWIO_BASE_URL=http://localhost:8080/ 走本地服务。已禁用（enabled=false）：离线兜底角色，断网时启用。

② 提供能力

（兜底）离线模式 draw.io 图表创建（本地 8080 实例）
