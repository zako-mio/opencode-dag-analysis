⑤ 为什么存在（why）

设计意图（官方）

为 Web UI 提供原生桌面能力（本地服务托管/更新/菜单/WSL），是独立于 @opencode-ai/app 的 Electron 分发层，将浏览器版应用无损提升为桌面应用而不污染 app 包。

改造关联

属官方底座，本机装配层未引用。官方依赖链：desktop 依赖 @opencode-ai/app + @opencode-ai/ui（package.json:39-40），是 app 包的唯一 Electron 宿主。

⑥ 怎么用（how）

怎么用

· 开发/构建：bun predev→electron-vite dev（package.json:14-18）；打包 electron-builder --config（package.json:19-23，main 指向 ./out/main/index.js）
· 主进程装配 src/main/index.ts:15-51：spawnLocalServer 拉起 sidecar、registerIpcHandlers、createMenu、setupAutoUpdater、WSL 控制器、migrate 与 store 清理
· 渲染进程 src/renderer/index.tsx 复用 @opencode-ai/app（index.tsx:3-17），经 preload 的 window.api 桥（index.tsx:64-321）访问原生能力

典型场景与协作

作为独立于 @opencode-ai/app 的 Electron 分发层：主进程管理本地 sidecar server 生命周期（main/server.ts）、原生菜单/深链/更新；渲染进程复用 app 的 AppInterface 只替换平台实现（onboarding.tsx:1-41 用 window.api 判断首次启动）。与 cli 形成双入口：desktop 面向图形用户、cli 面向终端用户，共享同一 server/core 后端。
