slack

oc-slack · package · G18-集成 · Layer 1

① 作用

Slack 机器人集成（@slack/bolt Socket Mode）。src/index.ts 创建 opencode 服务端实例（createOpencode）与 Slack App，按 channel+thread 键复用 session：首次消息创建 opencode session 并分享链接，后续消息走 session.prompt；同时订阅 message.part.updated 事件把 tool 完成状态回贴到 thread（src/index.ts:24-51）。

· Slack Socket Mode 机器人（src/index.ts:4）

· 会话分享链接回帖（src/index.ts:96）
· tool 执行状态回帖（message.part.updated 订阅，src/index.ts:24-51）
· /test 命令与错误兜底回复（src/index.ts:138）

⑤ 为什么存在（why）

设计意图（官方）

用 Socket Mode（无需公网回调）降低自托管门槛；一线程一会话的隔离保证多用户并发互不干扰；SDK（@opencode-ai/sdk）直连 server 复用完整会话/工具/分享协议，bot 只做 Slack 协议↔opencode 协议的翻译层。

改造关联

本机未改，且本机装配层刻意绕开 Slack（MEMORY 中飞书为协同入口，lark-suite skill 覆盖消息/日历/文档）。slack 包是官方 IM 接入参考：本机 lark-suite + lark-cli 即同类聊天平台↔AI 会话桥的飞书版。

⑥ 怎么用（how）

怎么用

bun dev（bun run src/index.ts）启动 Slack Bolt 机器人：env 需 SLACK_BOT_TOKEN / SLACK_SIGNING_SECRET / SLACK_APP_TOKEN（.env.example 提供）；App({socketMode:true}) 建立 Socket Mode 长连接；内部 createOpencode({port:0}) 起一个临时 opencode server，把每个 Slack 线程(channel-thread_ts)映射为独立 opencode session：收到消息 → client.session.create + session.share 分享链接 → session.prompt 发提示 → say() 回帖；订阅 message.part.updated 事件把 tool 完成状态实时回帖（app.client.chat.postMessage）。

典型场景与协作

把 opencode 接入 Slack 工作区：@机器人或在频道内对话即开启独立 AI 会话，工具调用进度与最终回答以线程化消息呈现，会话可分享（share URL）。
