⑤ 为什么存在（why）

历史引入动机

2026-08-04 随 Superpower 安装引入（OpenSpec 上游，author openspec）。实现完成并验证通过后归档：将 delta spec 合并到主 spec 并移动到 archive。引入动机：OpenSpec 的 Delta Spec 机制——变更中的 spec 是增量（ADDED/MODIFIED/REMOVED/RENAMED），归档时才合并到主 spec，保证并发变更与审视回滚能力（0803 解析报告）。
