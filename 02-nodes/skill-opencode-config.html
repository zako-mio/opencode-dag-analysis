⑥ 怎么用（how）

触发方式

触发关键词：opencode配置、opencode参数、opencode.jsonc、config schema、permission配置、provider配置、mcp配置、opencode设置、opencode文档、配置参考（SKILL.md description）。用户需要查看/修改/编写/验证 opencode 配置时。

工作流/用法

1) 三阶自检路由矩阵定位需求（改 Schema 参数到 ref/；查本项目实际配置到 local/；操作步骤到 ops/；故障到 troubleshooting/）；2) 修改 opencode.jsonc 前先备份（.bak-日期）；3) 修改后 JSON 验证 + 重算 SHA256 + 同步 SKILL.md 子文件哈希表 + 零旧值残留检查（MEMORY.md 0813 安全链）；4) 按 ops/security.md 编码安全规则（edit 优先，禁 python -c 管道）。

协作关系

与 opencode.jsonc 配置本体、auto-mode.md（配置同步安全链）、MEMORY.md（0813 修改安全链记录）、opencode 官方文档（Schema v2）、D:\Opencode_Download\Opencode-全量备份（备份链）协作。
