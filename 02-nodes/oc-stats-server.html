stats-server

oc-stats-server · package · G17-Stats · Layer 0

① 作用

Stats 后端 Node HTTP 服务（Effect HttpRouter + Bun，Dockerfile 部署）。src/server.ts 用 NodeHttpServer 启动 3000 端口服务并注入 Ingest 层，src/router.ts 暴露 GET /health、/ready 与 POST / 数据摄取端点（Bearer 鉴权 + 并发信号量限流），src/ingest.ts 将事件批处理写入 AWS Firehose，src/stat-sync.ts 是每小时 Athena 同步 daemon。

② 提供能力

· 摄取端点 POST /：事件批收 + Firehose 写入（src/router.ts:25、src/ingest.ts:38）
· 健康检查 GET /health 与 /ready（含优雅停机判定，src/router.ts:23-24）
· Bearer 鉴权（timingSafeEqual，src/router.ts:56）
· 每小时统计同步 daemon（src/stat-sync.ts:13）
· Docker 化部署（Dockerfile:1，turbo prune + bun install）
