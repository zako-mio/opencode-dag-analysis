skill-job-listing-filter · skill · A6i-简历求职 · Layer 0

① 作用

岗位表批量筛选方法论。当任务涉及从 xlsx/表格按城市/学历/届数/岗位类型/截止日期筛选招聘岗位，或用 openpyxl 解析 WPS 生成表格、设计关键词集与排除词、审计子Agent筛选结果时使用。触发关键词：岗位筛选、校招筛选、招聘表、openpyxl、WPS xlsx、styles.xml、关键词集、排除词、可疑行审计。

⑤ 为什么存在（why）

历史引入动机

源自 2026-08-24 校招岗位筛选实战（25MB 双总表→808 命中），由 reflection-worker 于 09-09 从 cycle_0824_job_filter 提炼，09-11 /reflection 采纳并安装至 skills/。

当前需求驱动

需求驱动：批量筛选 = 表结构定位 + WPS xlsx 格式兼容 + 筛选口径参数化 + 关键词/排除词规则 + 子Agent 审计；筛选结果的正确性不由子Agent 自检保证，而由主Agent 的结果级审计保证。

⑥ 怎么用（how）

触发方式

任务涉及从 xlsx/表格按城市/学历/届数/岗位类型/截止日期筛选招聘岗位、用 openpyxl 解析 WPS 生成表格、设计岗位类型关键词集与排除词、审计子Agent 筛选结果时加载。

工作流/用法

①表结构定位（列全 sheet 名、注意表头偏移、字段画像）；②WPS xlsx 解析兼容（复制副本→剥离/替换 styles.xml→重打包读副本）；③筛选口径参数化（截止日期 Excel 序列号 epoch 1899-12-30、学历、城市、届数）；④关键词集与排除词铁律（宽词必配行业硬件排除词，禁裸词跨领域泛词）；⑤算法特赦规则（含「算法」且不含「嵌入式」保留）；⑥委派子Agent（禁私扩关键词）+ 主Agent 结果级审计（可疑行抽样/审计脚本）。

协作关系

与 recruit-assist（招聘域）协作；依赖 openpyxl；check_suspect.py 类审计脚本随 skill 复用；依赖 config-main。
