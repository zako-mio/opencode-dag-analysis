⑥ 怎么用（how）

触发方式

触发关键词：网页设计、UI 页面、组件、配色、排版、布局、动效、可访问性、交互、表单、响应式、前端开发、landing page、设计系统；新建页面/组件、UI 重构、设计审查、配色/字体选型时（SKILL.md description）。

工作流/用法

1) Phase 1 数据驱动：python search.py '<产品> <行业> <风格>' --design-system -p 项目名，得到 3-5 个候选设计系统（可用 --domain/--stack 精化，0 结果时放宽关键词或降级内置优先级表）；2) Phase 2 设计主管裁决：挑候选/定制/超越，构建 token 系统（4-6 命名 hex + 2+ 字体角色 + ASCII wireframe + 签名元素），双轮审查（简报比对 + 唯一性测试）后确认编码；3) 交付前按 references/pro-rules.md 清单核对（图标/对比度/安全区域）。

协作关系

与 browser-harness（create-web preset 组合，浏览器实测渲染）、mission-archiving（HTML 版报告设计支撑）、create-web 特化 agent 协作。参考文件 design-philosophy/quick-reference/pro-rules 按需加载。
