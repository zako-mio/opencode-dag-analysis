llm

oc-llm · package · G5-LLM请求层 · Layer 4

① 作用

LLM 请求/协议层。src/index.ts:1-28 导出 LLMClient/Auth/Provider/Tool/ToolRuntime；核心 LLM 门面 src/llm.ts:45-48 提供 generate/stream 等请求方法。src/route/client.ts:29-49 定义 Route 结构（provider+protocol+endpoint+auth+transport）与 RequestExecutor；src/route/transport/http.ts、websocket.ts 实现 HTTP/WS 传输。内置 8 个 provider（src/providers/：anthropic、openai、google、azure、amazon-bedrock、openrouter 等，package.json:17-28）与 6 个协议适配（src/protocols/：anthropic-messages、openai-chat、openai-responses、gemini、bedrock-converse，package.json:29-35）。

② 提供能力

· 统一 LLM 客户端门面 generate/stream（packages/llm/src/llm.ts:45）
· Route 路由抽象：endpoint/auth/transport/body schema（packages/llm/src/route/client.ts:36-48）
· HTTP 与 WebSocket 传输层（packages/llm/src/route/transport/http.ts、websocket.ts）
· 多提供商适配：OpenAI/Anthropic/Google/Azure/Bedrock/OpenRouter/xAI 等（packages/llm/src/providers/）
· 多协议编解码：chat/responses/messages/gemini/bedrock（packages/llm/src/protocols/）
· Tool 定义与执行运行时（packages/llm/src/tool.ts、tool-runtime.ts）
· 上下文溢出检测（packages/llm/src/provider-error.ts:4）
